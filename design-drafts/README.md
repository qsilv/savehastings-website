# Theme drafts

Rough hero sketches of three alternative themes for the site. They are not part of the app and nothing links to them.

- **A, street sign:** safety orange page with black sign borders.
- **B, zine:** cream paper, black ink, orange spot colour.
- **C, pizza box:** kraft cardboard with orange and black print.

Each theme has a desktop and a phone-width version, as an HTML file and a PNG screenshot. Open the HTML files straight from this folder; they load photos and the logo from `../public`. Headlines in the drafts are placeholders.
